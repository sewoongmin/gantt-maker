# 간트차트 사용 설명서

연구개발 추진일정을 **브라우저에서 바로 그리고, 끌어 고치고, 그림·파일로 저장**하는 단일 페이지입니다.  
외부 라이브러리·서버가 필요 없습니다. 인터넷이 없어도 `index.html`만 열면 동작합니다.

- **웹에서 쓰기:** [https://sewoongmin.github.io/gantt-maker/](https://sewoongmin.github.io/gantt-maker/)
- **파일로 쓰기:** 이 폴더의 `index.html`을 브라우저로 엽니다.

처음 접속하면 `chart-config.js`에 들어 있는 기본 일정(최종안)이 보입니다.  
이후 편집 내용은 브라우저에 자동으로 임시 저장됩니다.

## 1. 화면 구성

위에서부터 네 구역입니다.

| 구역 | 역할 |
| --- | --- |
| **툴바** (위쪽 두 줄) | 기간, 편집/비교, 그림 저장, 파일, 버전 |
| **설정(JSON) 패널** | `설정(JSON)`을 눌렀을 때만 열림. 설정을 텍스트로 직접 고침 |
| **차트** (왼쪽) | 간트차트. 편집 모드에서 클릭·드래그 |
| **편집 패널** (오른쪽) | 선택한 요소의 문구·색·시점. 편집 모드가 켜져 있을 때만 보임 |

맨 아래 회색 안내 문구는 인쇄·PNG에는 들어가지 않습니다.

## 2. 처음 쓸 때

1. 페이지를 엽니다. 기본 일정이 이미 그려져 있습니다.
2. **편집 모드**가 켜져 있으면(기본값) 차트를 바로 고칠 수 있습니다.
3. 막대를 끌어 구간을 옮기고, 오른쪽 패널에서 문구를 고칩니다.
4. 툴바 오른쪽에 `브라우저에 임시 저장됨`이 뜨면 새로고침해도 작업이 남습니다.
5. 다른 사람과 공유하거나 백업하려면 **간트 내보내기**로 JSON을 받습니다.
6. 문서에 넣을 그림은 **PNG 저장**(배율 2x 권장) 또는 **인쇄 / PDF**를 씁니다.

브라우저 임시 저장은 **이 사이트·이 브라우저**에만 남습니다.  
다른 PC, 시크릿 창, 다른 브라우저에는 전달되지 않습니다. 영구 보관은 파일 내보내기를 쓰세요.

## 3. 툴바 — 모든 버튼

### 1행: 보기 · 편집 · 비교

| 항목 | 하는 일 |
| --- | --- |
| **기간** | 표에 그릴 시작 분기 ~ 끝 분기. 연도·분기 네 칸을 따로 고릅니다. 예: `2026 2Q ~ 2029 1Q` |
| **이동 단위** | 드래그·←→ 키가 붙는 칸. `1분기` / `½분기` / `¼분기`(기본) / `0.1분기` / `1개월` / `½개월` / `자유`. 표시 단위가 월로 바뀌면 자동으로 `1개월`이 됩니다 |
| **편집 모드** | 켜면 차트 클릭·드래그와 오른쪽 패널이 살아납니다. 끄면 보기 전용 |
| **되돌리기** | 직전 편집을 취소합니다. 최대 약 80단계. 입력칸에 커서가 있을 때는 `Ctrl+Z`가 글자 되돌리기로 동작 |
| **변경 비교** | 켜면 차트가 **위(변경 전) / 아래(변경 후)** 두 장으로 나뉩니다 |
| **기준 저장** | 지금 일정을 비교의 「변경 전」으로 고정합니다 |
| **변경 전으로** | 비교 기준 일정을 작업 화면으로 불러옵니다. 지금 작업은 되돌리기로 취소 가능 |
| **비교 요약** | 변경 비교가 켜져 있을 때 `추가 n` / `단축 n` / `지연 n` / `숨김 n` 칩이 뜹니다 |

### 2행: 그림 · 파일 · 버전

| 항목 | 하는 일 |
| --- | --- |
| **배율** | PNG를 몇 배로 뽑을지. `1x` ~ `4x`. 문서 삽입은 **2x 이상** 권장 |
| **PNG 저장** | 흰 배경 PNG 파일 다운로드. 변경 비교가 켜져 있으면 위·아래 두 차트가 한 장에 들어갑니다 |
| **SVG 저장** | 파워포인트·일러스트레이터에서 깨지지 않게 편집할 수 있는 벡터. 비교 모드면 두 차트가 한 SVG |
| **인쇄 / PDF** | 브라우저 인쇄. 용지는 **A4 가로**, 툴바·패널은 인쇄에서 숨겨집니다 |
| **간트 내보내기** | 현재 일정 + 비교 기준 + 버전 목록을 JSON 한 파일로 저장 |
| **간트 불러오기** | 위에서 받은 JSON, 또는 `chart-config.js`를 다시 엽니다 |
| **config.js 저장** | 지금 화면을 프로젝트용 `chart-config.js` 형태로 내려받습니다. 받은 파일로 기존 파일을 교체하면 기본값이 바뀝니다 |
| **설정(JSON)** | 화면 위에 JSON 편집창을 엽니다. **적용**을 눌러야 차트에 반영됩니다 |
| **파일 기준 초기화** | 브라우저 임시 저장을 지우고 `chart-config.js` 내용으로 되돌립니다 |
| **버전** 드롭다운 | 이름 붙여 둔 일정 목록. 비교 기준과 같으면 `· 비교 기준`이 붙습니다 |
| **버전 저장** | 지금 일정을 이름(기본: `최종안`)으로 보관. 같은 이름은 덮어쓸지 묻습니다. **최대 20개** |
| **이 버전으로** | 선택한 버전을 작업 화면으로 불러옵니다 |
| **비교 기준으로** | 선택한 버전을 변경 비교의 「변경 전」으로 씁니다 |
| **버전 삭제** | 목록에서만 지웁니다. 지금 작업 중인 차트는 그대로입니다 |
| **저장 상태** | `파일 기준` / `브라우저에 임시 저장됨` / `브라우저 임시 저장본 사용 중` |

### 3행: 표시 단위 · 그림 크기

| 항목 | 하는 일 |
| --- | --- |
| **표시 단위** | `자동` / `분기 (1Q~4Q)` / `월 (1월~12월)`. 자동은 보이는 기간이 **18개월 이하**면 월, 길면 분기 |
| **그림 가로 폭** | `자동`: 기간이 길든 짧든 그림 폭을 **약 1000px** 근처로 맞춥니다. `직접`: 슬라이더나 숫자 칸으로 px를 정합니다 |
| **글자 크기** | 60%~200%. 기간 축 폭은 그대로 두고 글자·행 높이·행 이름 칸만 커집니다 |
| **크기 초기화** | 표시 단위·그림 폭·글자 크기를 기본값으로 |
| **그림 크기 표시** | 지금 PNG 1x 기준 그림 크기(`그림 1000 × 380 px`)와 표시 단위 |

## 4. 차트에서 바로 고치기

**편집 모드**가 켜져 있어야 합니다.

### 막대(구간)

| 동작 | 결과 |
| --- | --- |
| **몸통**을 좌우로 드래그 | 길이를 유지한 채 구간 이동 |
| **왼쪽 끝점** 드래그 | 시작 시점만 변경 |
| **오른쪽 끝점** 드래그 | 끝 시점만 변경 |
| **문구**를 위아래로 드래그 | 글자 높이(`labelDy`). 막대에서 멀면 점선으로 연결 |
| 클릭 | 오른쪽 패널에서 세부 편집 |
| 더블클릭 | 오른쪽 패널의 문구 칸으로 바로 이동 |

끝점이 서로 겹쳐 있어도, **이미 선택한 막대**의 끝점이 우선입니다.

### 이벤트 점 · 산출물 · 마일스톤

| 동작 | 결과 |
| --- | --- |
| 도형/삼각형을 좌우로 드래그 | 시점(`at`) 변경 |
| 문구를 위아래로 드래그 | 글자 높이. 마일스톤은 삼각형 위/아래(`titleDy`) |
| 클릭 / 더블클릭 | 선택 · 문구 칸 포커스 |

### 범례

- **항목**(아이콘+글자)을 클릭하면 그 항목의 문구·색·모양·순서를 고칩니다.
- **범례 박스의 빈 곳**을 클릭하면 제목과 표시 여부를 고칩니다.

### 변경 비교가 켜져 있을 때

- **아래 차트(변경 후)**만 편집할 수 있습니다. 위(변경 전)는 보기 전용입니다.
- **추가 / 단축 / 지연** 알약을 클릭하면 그 표시의 색·문구를 바꿀 수 있습니다.
- 알약을 **위아래로 드래그**하면 그 일정의 비교 표시 높이만 조절됩니다.

빈 곳을 클릭하면 선택이 해제되고, 오른쪽 패널에 **전체 요소 목록**이 나옵니다.

## 5. 오른쪽 편집 패널

선택이 없으면 행·구간·점·산출물·마일스톤이 목록으로 나옵니다.  
이름을 누르면 선택, `×`를 누르면 삭제합니다.

패널 맨 위 버튼으로 새 요소를 넣습니다. **+ 구간 / + 이벤트 점 / + 산출물**은 지금 선택된 행(없으면 첫 행)에 붙습니다.

| 버튼 | 기본값 |
| --- | --- |
| **+ 행** | 빈 행 하나 추가 |
| **+ 마일스톤** | 기간 한가운데, 빨간 삼각형, 첫 행→마지막 행 점선 |
| **+ 범례** | `선 (단색)` 항목 하나 |
| **+ 구간** | 직전 구간 끝에서 약 2분기 길이, 문구 `새 구간`, 양끝 빈 동그라미 |
| **+ 이벤트 점** | 기간 한가운데, 남색 꽉 찬 점, 문구 `이벤트` |
| **+ 산출물** | 기간 한가운데, 초록 다이아몬드, 문구 `산출물` |

구간·점·산출물·마일스톤·범례 항목은 패널 아래 **복제** / **삭제**로 복사하거나 지울 수 있습니다.

### 구간(막대)

| 항목 | 설명 |
| --- | --- |
| **문구** | Enter로 두 줄. `\n`과 같습니다 |
| **색** | 후보색 버튼, 맨 오른쪽 색상 상자, 또는 **자동**(행의 교대 색) |
| **굵기** | 얇게 / 기본 / 굵게 / 아주 굵게 |
| **시작 · 끝** | 연도 / 분기 / 분기 안 위치(시작·¼·중간·¾) + ◀▶ 미세 이동 |
| **문구 위치** | 왼쪽 / 중앙 / 오른쪽 + ▲▼ (px). 차트에서 문구를 드래그해도 됩니다 |
| **끝 모양** | 시작/끝 각각: 빈 동그라미, 꽉 찬 점, 다이아몬드, 화살표, 없음 |
| **비교 표시** | 변경 비교가 켜져 있거나 이미 숨김/오프셋이 있을 때 나타남. 이 일정만 알약 숨기기, 높이 조절 |

### 이벤트 점 · 산출물

| 항목 | 설명 |
| --- | --- |
| **문구** | Enter로 두 줄 |
| **모양** | 꽉 찬 점, 빈 동그라미, 다이아몬드, 삼각형, 사각형, 별 |
| **색 · 시점 · 크기** | 작게 / 기본 / 크게 |
| **문구 위치** | 위 / 아래 + ▲▼. 위↔아래를 바꾸면 기본 간격으로 돌아갑니다 |

산출물의 기본 모양은 다이아몬드, 문구는 아래쪽입니다. 이벤트 점은 꽉 찬 점 + 위쪽 문구가 기본입니다.

### 마일스톤

| 항목 | 설명 |
| --- | --- |
| **문구** | 삼각형 옆(또는 아래)에 표시. 줄바꿈 유지 |
| **세부 목록** | 한 줄에 하나. 앞에 `•`가 자동으로 붙습니다 |
| **문구 높이** | 삼각형 기준 위/아래. 0이면 기본(아래). 멀면 점선 |
| **색 · 시점** | 색 후보군 + 시점 드롭다운 |
| **표시 위치** | 어느 행 **안**에 삼각형을 둘지, 또는 **표 아래** |
| **점선 시작** | 없음 / 표 맨 위 / 특정 행부터 |
| **점선 끝** | 삼각형까지 / 특정 행까지 / 표 아래까지 |
| **점선 모양** | 점선 / 실선 / 없음 |
| **삼각형** | 표시 / 숨김 |

예: 1행에서 2행으로 이어지는 점검선은  
`점선 시작 = 비행시험`, `점선 끝 = 상황인지`, `표시 위치 = 상황인지 안`.

### 행

| 항목 | 설명 |
| --- | --- |
| **행 이름** | 줄바꿈하면 두 줄 |
| **행 높이** | 비우거나 **자동**이면 문구·마일스톤이 잘리지 않게 늘어납니다. `−` `+`로 수동 조절(최소 40px) |
| **막대 위치** | 행 안에서 막대를 ▲▼로 살짝 옮김 |
| **▲ 위로 / ▼ 아래로** | 행 순서 변경. 마일스톤 점선이 가리키는 행 번호도 같이 맞춰집니다 |
| **행 삭제** | 그 행의 구간·점·산출물이 함께 지워집니다 |

`layout.rowHeight`는 **최소 높이**입니다. 내용이 많으면 행이 자동으로 더 커지고, 막대는 남은 공간의 가운데에 놓입니다.

### 범례 · 범례 항목

- 범례: 제목(비우면 제목 없음), 표시/숨김, 항목 목록
- 항목 모양: **선(단색)** / **선(두 색 교대)** / **점·도형** / **점선+삼각형** / **삼각형**
- 두 색 교대는 첫 번째·두 번째 색을 따로 고릅니다
- 점/도형일 때는 점 모양을 고를 수 있습니다
- **◀ 앞으로 / 뒤로 ▶**로 순서를 바꿉니다

## 6. 기간 · 시점 · 이동 단위

### 표 기간

툴바 **기간**은 표의 칸이 어디서 어디까지인지만 정합니다.  
연도 전체를 채울 필요가 없습니다. `2026 2Q ~ 2029 1Q`이면 2026년은 2Q부터, 2029년은 1Q까지만 칸이 생깁니다.

설정 파일에서는 이렇게 씁니다.

```js
range: { start: '2026-Q2', end: '2029-Q1' },
periodLabels: ['1Q', '2Q', '3Q', '4Q'],
```

`periodLabels`를 `['상반기', '하반기']`처럼 바꾸면 반기 단위 표가 됩니다.  
이 배열을 바꾸는 것은 JSON / `chart-config.js`에서만 가능합니다.

### 시점 표기

`start`, `end`, `at`에 아래 형식을 섞어 쓸 수 있습니다.

| 표기 | 의미 |
| --- | --- |
| `"2026-Q3"` | 2026년 3분기가 **시작되는** 지점 |
| `"2026-Q3.25"` | 3분기의 ¼ 지점 (이동 단위 ¼분기와 맞춤) |
| `"2026-Q3.5"` | 3분기의 중간 |
| `"2026-Q3.75"` | 3분기의 ¾ 지점 |
| `"2028-Q4.9"` | 4분기의 90% 지점 |
| `"2026-08"` | 2026년 8월 1일 |
| `"2026-08-15"` | 2026년 8월 15일 |

화면의 시점 칸은 **연도 / 분기 / 분기 안 위치** 드롭다운과 ◀▶로 고칩니다.  
이동 단위가 ¼분기이면 드래그도 0 / 0.25 / 0.5 / 0.75에 붙습니다. **자유**는 칸에 붙이지 않습니다.

### 이동 단위와 키보드

- 드래그 스냅 = 툴바 **이동 단위**
- `←` `→` = 선택한 요소를 이동 단위만큼 좌우로
- 이동 단위가 `자유`(0)이면 키 이동은 0.05분기 단위입니다

### 월 단위 표시 (1월~12월)

기간이 짧을 때(예: `2027 1Q ~ 2027 4Q`) 헤더가 자동으로 **1월~12월**이 되고, 세로선도 달마다 그어집니다.  
툴바 **표시 단위**로 분기/월을 직접 고를 수도 있습니다.

- 월 단위일 때 화면에서 고친 시점은 `"2027-03"`(3월 1일), `"2027-03-15"`처럼 저장됩니다.
- 분기 표기(`"2027-Q2"`)로 적어 둔 기존 일정도 그대로 맞는 자리에 그려집니다. 단위를 바꿔도 일정은 움직이지 않습니다.
- 오른쪽 패널의 시점 칸은 **연도 / 월 / 일(1일·15일)** 로 바뀝니다.
- 칸이 좁으면 `3월` 대신 `3`만, 아주 좁으면 1·4·7·10월만 표시합니다.

## 6-1. 그림 크기 맞추기

왼쪽 「일자」 칸은 고정이고 기간 칸이 늘었다 줄었다 하기 때문에, 문서에 넣으면 기간이 길 때 글자가 작아지고 짧을 때는 그림이 위아래로만 길어 보입니다. 툴바 3행으로 맞춥니다.

| 상황 | 이렇게 |
| --- | --- |
| 어떤 기간이든 비슷한 크기로 | **그림 가로 폭 = 자동** (기본). 칸 폭이 자동으로 늘거나 줄어 그림 폭이 약 1000px로 유지됩니다 |
| 문서 칸에 딱 맞는 폭이 필요 | **직접**으로 바꾸고 px 입력 (예: 한글 문서 본문 폭에 맞춰 1200) |
| 문서에 넣으니 글자가 작다 | **글자 크기**를 120~150%로. 그림 폭은 그대로라 글자가 확실히 커 보입니다 |
| 기간이 너무 길다 (5년 이상) | 자동이어도 칸이 일정 폭 아래로는 줄지 않아 그림이 넓어집니다. **기간 축약**을 같이 쓰세요 |

설정 파일에서는 `layout`에 넣습니다.

```js
timeUnit: 'auto',          // 'auto' | 'quarter' | 'month'
layout: {
  widthMode: 'auto',       // 'auto' | 'manual'
  autoWidth: 1000,         // 자동일 때 목표 그림 폭(px)
  chartWidth: 1200,        // 직접일 때 그림 폭(px)
  fontScale: 1.3           // 글자 배율
}
```

## 7. 색

막대에 색을 **지정하지 않으면** `barColorCycle` 순서대로 번갈아 칠합니다(기본: 하늘색 → 남색).  
오른쪽 패널에서 **자동**을 누르면 다시 이 교대 색으로 돌아갑니다.

개별 지정은 색 버튼(후보군) 또는 맨 오른쪽 색상 상자입니다.

```js
barColorCycle: ['sky', 'navy'],
palette: [
  { name: 'sky',  label: '하늘색', color: '#9DC3E6' },
  { name: 'navy', label: '남색',   color: '#1F3864' },
  { name: 'gold', label: '금색',   color: '#BF9000' }
]
```

`palette`에 이름을 추가하면 편집 화면의 색 후보군에 바로 나타납니다.  
금색(`gold`)은 보통 **체계 통합 · 고도화** 구간에 씁니다.

행마다 배경을 다르게 하려면 JSON에서 그 행에 `fill`(표 영역) 또는 `labelFill`(행 이름 칸)을 넣습니다.

```js
{ label: '검증', fill: '#FFF7E6', labelFill: '#EEE', bars: [] }
```

격자·격행 배경:

```js
layout: {
  showPeriodGrid: true,      // 1Q, 2Q … 세로선
  periodGridStyle: 'solid',  // 'solid' | 'dashed'
  showYearGrid: true,        // 연도 경계(더 진함)
  zebra: true,               // 한 행씩 건너뛰며 배경
  zebraStart: 1              // 0 = 첫 행부터, 1 = 둘째 행부터
},
colors: {
  header: '#404040',
  subHeader: '#F2F2F2',
  gridYear: '#A8ADB6',
  gridPeriod: '#D4D8DF',
  rowAlt: '#F5F7FB',
  text: '#000000'
}
```

## 8. 변경 비교

두 시점의 일정을 위·아래로 놓고, 무엇이 **추가·단축·지연**됐는지 표시합니다.

### 권장 순서

1. 확정된 일정을 **기준 저장**하거나, 저장된 버전을 **비교 기준으로** 지정합니다.
2. 아래(작업 화면)에서 구간·마일스톤을 고칩니다.
3. **변경 비교**를 켭니다.
4. 위 = 변경 전, 아래 = 지금. PNG/SVG 저장 시 두 장이 함께 들어갑니다.

### 표시 의미

| 표시 | 언제 뜨는지 |
| --- | --- |
| **추가** | 기준에 없던 구간·점·마일스톤 (같은 `id`가 기준에 없음) |
| **단축** | **끝 시점**이 앞당겨짐 (점·마일스톤은 `at`이 앞당겨짐) |
| **지연** | **끝 시점**이 뒤로 밀림 |
| **기존 일정** | 바뀌기 전 시점. 아래 차트에 점선(고스트)으로 표시 |

구간은 **종점(end)만** 보고 단축/지연을 판단합니다.  
시작만 옮기고 끝이 같으면 마커가 뜨지 않습니다.

비교의 「변경 전」차트는 **날짜만** 기준본을 쓰고, 문구 간격·행 높이 등 모양은 지금 차트를 따릅니다. 그래서 위·아래 레이아웃이 어긋나지 않습니다.

### 알약 꾸미기

- 알약 또는 범례의 비교 항목을 클릭 → 색·표시 문구 변경
- **기본값으로** 누르면 추가=`#E11D48`, 단축=`#EF4444`, 지연=`#EA580C`, 기존 일정=`#FB7185`
- 일정마다 **숨기기**: 그 구간의 「비교 표시 → 숨기기」
- 높이: 알약 드래그, ↑↓, 또는 「비교 표시 높이」▲▼ (2px / 6px 단위)

숨긴 개수는 툴바 요약에 `숨김 n`으로 나옵니다.

## 9. 버전 저장

작업 중간 상태를 이름 붙여 브라우저에 보관합니다. 예: `기존 안`, `최종안`, `검토용`.

| 동작 | 설명 |
| --- | --- |
| **버전 저장** | 이름을 묻습니다. 기본 제안은 `최종안`(이미 있으면 `최종안 2` …) |
| 같은 이름 | 덮어쓸지 확인합니다 |
| **이 버전으로** | 작업 화면을 그 버전으로 교체. 변경 비교는 꺼집니다 |
| **비교 기준으로** | 작업 화면은 그대로 두고, 비교의 「변경 전」만 그 버전으로 |
| **버전 삭제** | 목록에서만 삭제 |

버전은 **최대 20개**입니다. 이 브라우저의 저장 공간에만 남으므로, 중요한 안은 **간트 내보내기**로 파일도 받아 두세요. JSON 안에는 `versions` 배열이 함께 들어갑니다.

## 10. 저장 · 불러오기 · 초기화

세 층이 있습니다.

| 층 | 어디에 남나 | 언제 쓰나 |
| --- | --- | --- |
| **브라우저 임시 저장** | 이 PC의 이 브라우저 | 편집할 때마다 자동. 새로고침해도 유지 |
| **버전** | 같은 브라우저 | 초안/최종안처럼 여러 안을 오갈 때 |
| **파일** | 디스크 | 백업, 다른 사람 전달, GitHub Pages 기본값 교체 |

### 간트 내보내기 / 불러오기

내보낸 JSON 구조:

```json
{
  "version": 2,
  "type": "gantt-chart",
  "savedAt": "2026-08-13T12:34:21.980Z",
  "config": { },
  "baseline": { },
  "versions": [ ]
}
```

불러오면 일정뿐 아니라 **비교 기준**과 **버전 목록**도 함께 복원됩니다.  
순수 설정 객체(`rows`가 있는 JSON)나 `chart-config.js`도 같은 버튼으로 열 수 있습니다.

### 설정(JSON) 패널

`설정(JSON)` → 텍스트를 고친 뒤 **적용**.  
주석·후행 콤마가 있는 JS 객체 형태도 읽습니다. 간트 패키지 JSON을 붙여 넣어도 됩니다.

### 파일 기준 초기화

브라우저에 쌓인 임시본을 버리고, 페이지가 처음 실었던 `chart-config.js`로 돌아갑니다.  
비교 기준·버전 목록은 지우지 않습니다.

### Pages / 다른 사람에게 기본값으로 보이게

1. 화면에서 일정을 맞춥니다.
2. **config.js 저장**으로 `chart-config.js`를 받습니다.
3. 프로젝트의 `chart-config.js`를 그 파일로 교체하고 GitHub `main`에 올립니다.
4. 처음 접속하는 사람은 그 내용이 기본 차트로 보입니다.

이미 열어 본 사람은 브라우저 임시 저장이 우선일 수 있습니다. 그때는 **파일 기준 초기화**를 누르거나, 시크릿 창으로 확인하세요.

## 11. PNG / SVG / 인쇄(PDF)

| 방식 | 특징 |
| --- | --- |
| **PNG** | 흰 배경 래스터. 배율 1x~4x. 메일·한글/워드 삽입용 |
| **SVG** | 벡터. 파워포인트·일러스트에서 글자·선을 다시 고칠 수 있음 |
| **인쇄 / PDF** | 브라우저 인쇄 대화상자. `@page`가 A4 가로, 여백 10mm. 툴바·패널·안내 문구는 숨김 |

편집용 클릭 영역(투명 히트박스)과 선택 파란 테두리는 저장 파일에 **들어가지 않습니다**.

변경 비교가 켜져 있으면 PNG/SVG 모두 **위: 변경 전, 아래: 변경 후**가 한 파일입니다.

## 12. 설정 파일(`chart-config.js`) 직접 편집

이 파일만 고치고 새로고침해도 차트가 바뀝니다. 화면에서 맞춘 뒤 **config.js 저장**으로 받아 교체하는 방법이 더 안전합니다.

### 최상위 키

```js
window.GANTT_CONFIG = {
  title: '',
  subtitle: '',
  range: { start: '2026-Q2', end: '2029-Q1' },
  periodLabels: ['1Q', '2Q', '3Q', '4Q'],
  cornerLabel: '일자',
  palette: [ /* … */ ],
  barColorCycle: ['sky', 'navy'],
  colors: { /* … */ },
  layout: { /* … */ },
  rows: [ /* … */ ],
  milestones: [ /* … */ ],
  compareStyle: { /* … */ },
  legend: { /* … */ }
};
```

`title` / `subtitle`은 차트 맨 위 가운데에 그려집니다. 화면 패널에는 칸이 없으므로 JSON에서 넣습니다. `\n`으로 여러 줄.

### 행 · 구간 · 점 · 산출물

```js
{
  label: '통신 / 지상국',   // \n 으로 두 줄
  height: 96,              // 생략하면 자동
  barDy: 0,                // 막대를 행 안에서 위아래로
  fill: '#FFF7E6',         // 선택: 이 행만 배경
  bars: [
    {
      id: 'b-link-1',
      start: '2026-Q2', end: '2027-Q2.5',
      label: '데이터링크 설계',
      labelAt: 0.5,          // 0.15 왼쪽 / 0.5 중앙 / 0.85 오른쪽
      labelDy: -12,          // 음수 = 막대 위
      width: 3,
      capStart: 'circle', capEnd: 'circle',
      compareHidden: false,
      compareOffsetDy: 0
    }
  ],
  markers: [
    { id: 'm-1', at: '2027-Q2.5', type: 'filled', color: 'navy',
      label: '설계 검토', labelPos: 'above', labelDy: -12 }
  ],
  deliverables: [
    { id: 'd-1', at: '2028-Q2', type: 'diamond', color: 'green',
      label: '시험 성적서', labelPos: 'below' }
  ]
}
```

- `id`는 변경 비교가 같은 항목을 짝지을 때 씁니다. 화면에서 추가하면 자동으로 붙습니다. 지우지 마세요.
- 한 행에 막대를 두 줄로 쌓으려면 막대에 `dy: -10`, `dy: 10`을 줍니다.
- `bars: []`이면 그 행은 마일스톤·산출물만 담는 행이 됩니다(예: 검증).

### 마일스톤

```js
{
  id: 'ms-mid',
  at: '2027-Q3',
  row: 1,              // 삼각형 위치. null 이면 표 아래
  fromRow: 0,          // 점선 시작. 'top' | 행번호 | null
  toRow: 1,            // 점선 끝. 생략하면 삼각형까지, 'bottom' = 표 아래
  line: 'dashed',      // 'dashed' | 'solid' | 'none'
  triangle: true,
  color: 'red',
  title: '실기체 연동\n중간 점검',
  titleDy: 10,         // 0 = 삼각형 아래, 음수 = 위
  items: ['세부 1', '세부 2']
}
```

### 범례 · 비교 스타일

```js
legend: {
  show: true,
  title: '범례',
  items: [
    { type: 'lineAlt', colors: ['sky', 'navy'], label: '알고리즘 개발' },
    { type: 'line', color: 'gold', label: '체계 통합 · 고도화' },
    { type: 'marker', marker: 'filled', color: 'navy', label: '주요 이벤트' },
    { type: 'milestone', color: 'red', label: '핵심 마일스톤 (데모)' },
    { type: 'triangle', color: 'steel', label: '개발 마일스톤' }
  ]
},
compareStyle: {
  add:     { fill: '#E11D48', label: '추가' },
  shorten: { fill: '#EF4444', label: '단축' },
  delay:   { fill: '#EA580C', label: '지연' },
  ghost:   { fill: '#FB7185', label: '기존 일정' }
}
```

### 레이아웃 숫자 (필요할 때만)

대부분은 기본값으로 충분합니다. `gantt.js`의 기본값과 합쳐집니다.

| 키 | 의미 |
| --- | --- |
| `padding` | 차트 바깥 여백 |
| `labelColWidth` | 왼쪽 행 이름 칸 너비 |
| `widthMode` / `autoWidth` / `chartWidth` | 그림 가로 폭 (자동·직접). 분기 칸 폭은 여기서 계산됩니다 |
| `fontScale` | 글자·행 높이 배율 |
| `yearHeaderHeight` / `periodHeaderHeight` | 연도·분기 헤더 높이 |
| `rowHeight` | 행 최소(참고) 높이 |
| `rowPadding` | 자동 높이일 때 위·아래 여유 |
| `rowMilestoneOffset` | 막대 기준선 대비 삼각형 (음수면 위) |
| `calloutGap` 등 | 표 아래 마일스톤 영역 |
| `rowComparePad` | 변경 비교 알약이 들어갈 아래쪽 여유 |

## 13. 단축키

입력칸(`input` / `textarea` / `select`)에 커서가 있으면 아래 키는 차트에 적용되지 않습니다.

| 키 | 동작 |
| --- | --- |
| **클릭** | 선택 |
| **더블클릭** | 문구 입력칸으로 이동 |
| **Delete** / **Backspace** | 선택한 요소 삭제 (행·범례 박스·비교 스타일은 해당 없음) |
| **Esc** | 선택 해제 |
| **←** **→** | 이동 단위만큼 시점 이동 (막대는 길이 유지) |
| **↑** **↓** | 문구(또는 비교 알약) 높이 4px |
| **Shift+↑↓** | 같은 높이 조절, 12px |
| **Ctrl+Z** (Mac: **⌘Z**) | 되돌리기 |

마우스로 문구·알약을 위아래 드래그하면 2px 단위로 붙습니다.

## 14. 파일 구성

```
index.html        페이지 (툴바 + 차트 + 편집 패널)
chart-config.js   기본 차트 내용 — 처음 접속 시 이 파일이 보입니다
gantt.js          SVG 렌더러, PNG/SVG 내보내기
editor.js         클릭·드래그·인스펙터
compare.js        변경 비교(추가·단축·지연), 두 장 PNG/SVG
app.js            툴바, 기간, 버전, 임시 저장
style.css         화면 테두리·툴바 스타일 (차트 색과는 별개)
```

의존성 설치가 없습니다. GitHub Pages는 `main` 브랜치 루트를 그대로 배포합니다.

## 15. 자주 하는 작업

**문구가 겹칠 때**  
문구를 드래그하거나 ↑↓, 인스펙터의 왼쪽/중앙/오른쪽·위/아래를 바꿉니다. 행이 좁으면 행을 선택해 높이를 키웁니다.

**막대가 너무 붙어 보일 때**  
끝 모양을 `없음`으로 바꾸거나, 한쪽만 동그라미를 남깁니다. 굵기를 얇게 해도 됩니다.

**검증 행처럼 막대 없이 마일스톤만**  
행의 구간을 모두 지우고 마일스톤의 표시 위치·점선 시작/끝을 그 행에 맞춥니다.

**기존 안 vs 최종안을 한 장에**  
기존 안을 버전으로 저장 → 최종안을 작업 → 기존 안을 **비교 기준으로** → **변경 비교** 켜기 → PNG 저장.

**다른 사람에게 링크만 주기**  
[https://sewoongmin.github.io/gantt-maker/](https://sewoongmin.github.io/gantt-maker/)  
그 사람이 고친 내용은 그 사람 브라우저에만 남습니다. 공유하려면 그 사람이 **간트 내보내기**한 JSON을 받으면 됩니다.

**내가 고친 것을 사이트의 기본값으로**  
config.js 저장 → 저장소의 `chart-config.js` 교체 → `main`에 푸시.

**화면이 예전 차트로 돌아갈 때**  
브라우저 임시 저장이 우선입니다. **파일 기준 초기화**, 또는 **간트 불러오기**로 원하는 JSON을 다시 엽니다.
