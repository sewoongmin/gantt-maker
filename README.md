# 간트차트 (HTML / SVG)

추진일정 간트차트를 그리는 단일 페이지입니다. 외부 라이브러리·인터넷 연결이 필요 없고,
`index.html` 을 브라우저로 열면 바로 보이며 **차트를 직접 끌어서 일정을 고칠 수 있습니다.**

```
index.html        페이지(툴바 + 차트 + 편집 패널)
chart-config.js   ★ 차트 내용(기간/행/구간/마일스톤/범례) — 파일로 관리할 때 고치는 곳
gantt.js          렌더러(SVG 생성, PNG/SVG 내보내기)
editor.js         차트 직접 편집(드래그 · 클릭 · 인스펙터)
app.js            툴바 / 기간 설정 / 되돌리기 / 저장
style.css         화면 스타일(차트 자체 스타일과 무관)
```

## 1. 차트에서 바로 고치기 (편집 모드)

툴바의 **편집 모드**가 켜져 있으면 차트가 편집기가 됩니다.

| 동작 | 결과 |
| --- | --- |
| 막대 **몸통** 드래그 | 길이를 유지한 채 구간 이동 |
| 막대 **양 끝점** 드래그 | 시작 / 끝 시점 변경 |
| 점 · 산출물 · 마일스톤 드래그 | 시점 변경 |
| 클릭 | 오른쪽 패널에서 문구 · 색 · 시점 · 모양 편집 (범례 항목도 클릭해서 수정) |
| 더블클릭 | 문구 입력칸으로 바로 이동 |
| `Delete` | 선택한 요소 삭제 |
| `←` `→` | 선택한 요소를 한 칸(이동 단위)씩 미세 이동 |
| `Ctrl+Z` | 되돌리기 |
| `Esc` | 선택 해제 |

- **이동 단위**(툴바)로 드래그 스냅을 정합니다. `1분기 / ½ / ¼ / 0.1 / 자유`
- 아무것도 선택하지 않으면 오른쪽 패널에 **전체 요소 목록**이 나옵니다.
  여기서 항목을 골라 선택하거나 `×` 로 지울 수 있습니다.
- `+ 행` `+ 구간` `+ 이벤트 점` `+ 산출물` `+ 마일스톤` 버튼으로 새 요소를 추가합니다.
- 편집 결과는 브라우저에 자동 임시 저장됩니다(툴바 오른쪽에 상태 표시).
  영구 보관은 **chart-config.js 저장** 을 눌러 받은 파일로 기존 파일을 교체하세요.
  임시 저장을 버리고 파일 내용으로 돌아가려면 **파일 기준 초기화** 를 누릅니다.

## 2. 전체 기간 (연도 단위로 맞출 필요 없음)

툴바의 **기간** 드롭다운에서 시작·끝 분기를 직접 고릅니다. 예: `2026 2Q ~ 2029 2Q`
→ 첫 연도는 2Q부터, 마지막 연도는 2Q까지만 표의 칸이 생깁니다.

설정 파일에서는 이렇게 씁니다.

```js
range: { start: '2026-Q2', end: '2029-Q2' },
periodLabels: ['1Q', '2Q', '3Q', '4Q'],   // ['상반기','하반기'] 처럼 반기 단위도 가능
```

## 3. 색 정하기

막대에 `color` 를 **적지 않으면** `barColorCycle` 순서대로 번갈아 칠합니다(기본: 하늘색 → 남색).
개별로 정하려면 막대를 클릭해 색 버튼(후보군)을 누르거나, 맨 오른쪽 색상 상자로 직접 지정합니다.
`자동` 버튼을 누르면 다시 교대 색으로 돌아갑니다.

```js
barColorCycle: ['sky', 'navy'],
palette: [
  { name: 'sky',  label: '하늘색', color: '#9DC3E6' },
  { name: 'navy', label: '남색',   color: '#1F3864' },
  { name: 'gold', label: '금색',   color: '#BF9000' }
  /* 여기에 이름을 추가하면 편집 화면의 색 후보군에 바로 나타납니다 */
]
```

## 4. 마일스톤 · 산출물의 위치와 점선

마일스톤은 **행 안**에도, **표 아래**에도 놓을 수 있고, 점선의 **시작행과 끝행**을 각각 지정합니다.

```js
{
  at: '2027-Q3.05',
  row: 2,            // 삼각형 + 설명을 표시할 행(0 = 첫 행). null 이면 표 아래
  fromRow: 0,        // 점선 시작 행. 'top' = 표 맨 위, null = 점선 없음
  toRow: 2,          // 점선 끝 행. 생략하면 삼각형까지, 'bottom' = 표 아래까지
  line: 'dashed',    // 'dashed' | 'solid' | 'none'
  triangle: true,
  title: '컴페니언 보드\n동작 테스트',
  items: ['세부 항목 1', '세부 항목 2']   // 불릿(•) 목록, 없으면 생략
}
```

- **1행에서 2행으로 가는 마일스톤** : `fromRow: 0, toRow: 1, row: 1`
- 계약 · 행정 이벤트(하늘색 삼각형)도 같은 방식으로 점선을 그립니다.
  색만 다르게 주면 됩니다: `color: 'steel', line: 'dashed', fromRow: 0, toRow: 2`
- 인스펙터에서는 `표시 위치` / `점선 시작` / `점선 끝` 드롭다운으로 고릅니다.
- 산출물은 각 행의 `deliverables` 에 넣습니다. 기본 모양은 초록 다이아몬드 + 아래쪽 글자입니다.
- 어떤 행이든 `bars` 는 있어도 되고 없어도 됩니다. `bars: []` 로 두거나 통째로 지우면
  그 행은 마일스톤·산출물만 담는 행이 됩니다(예: '검증' 행).

### 행 높이 자동 맞춤

`layout.rowHeight` 는 **최소 높이**입니다. 어떤 행에 마일스톤·산출물·여러 줄 문구가 들어오면
글자가 잘리지 않도록 그 행의 높이가 자동으로 늘어나고, 막대는 남은 공간의 가운데에 놓입니다.
직접 조절하려면 인스펙터의 `높이`(최소값)와 `막대 위치 ▲▼`(= `barOffset`)를 쓰세요.

## 4-1. 격자와 배경

```js
layout: {
  showPeriodGrid: true,      // 1Q, 2Q … 마다 세로 구분선
  periodGridStyle: 'solid',  // 'solid' | 'dashed'
  showYearGrid: true,        // 연도 경계선(더 진하게)
  zebra: true,               // 한 행씩 건너뛰며 배경색
  zebraStart: 1              // 0 = 첫 행부터 칠하기, 1 = 두 번째 행부터
},
colors: {
  gridYear: '#A8ADB6',       // 연도 경계선 색
  gridPeriod: '#D4D8DF',     // 분기 세로선 색
  rowAlt: '#F5F7FB'          // 격행 배경색 (옅은 음영)
}
```

행마다 다른 색을 주고 싶으면 그 행에 `fill: '#FFF7E6'`(표 영역) 또는
`labelFill: '#EEE'`(행 이름 칸)을 직접 지정합니다.

## 5. 시점(날짜) 표기법

`start`, `end`, `at` 에 아래 형식을 자유롭게 섞어 쓸 수 있습니다.

| 표기 | 의미 |
| --- | --- |
| `"2026-Q3"` | 2026년 3분기 시작점 |
| `"2026-Q3.5"` | 2026년 3분기의 중간 (소수 = 분기 내 비율) |
| `"2028-Q4.9"` | 2028년 4분기의 90% 지점 |
| `"2026-08"` | 2026년 8월 1일 |
| `"2026-08-15"` | 2026년 8월 15일 |

## 6. 변경 비교 (위·아래 두 차트)

툴바의 **변경 비교**를 켜면 차트가 **위·아래 두 개**로 나뉩니다.

- **위 = 변경 전** (기준 저장 시점의 일정)
- **아래 = 변경 후** (지금 편집 중인 일정) — 여기에만 변경 표시가 그려집니다.

| 표시 | 의미 |
| --- | --- |
| 추가 | 기준에 없던 구간·점·마일스톤 |
| 단축 | 끝 시점이 앞당겨지거나 기간이 짧아짐 |
| 지연 | 끝 시점이 뒤로 밀리거나 기간이 길어짐 |
| 기존 일정 | 바뀌기 전 시점 (아래 차트에 점선으로 표시) |

단축·지연 화살표와 알약은 **막대 아래쪽**에 놓여 기존 문구를 가리지 않습니다.
아래 차트의 알약/범례를 **클릭**하면 색과 문구를 바꿀 수 있습니다 (`compareStyle`).

사용 순서:
1. 일정을 확정한 뒤 **기준 저장** (= 변경 전).
2. 구간·마일스톤을 수정.
3. **변경 비교**를 켜 위·아래를 대조. PNG/SVG 저장 시 두 차트가 함께 저장됩니다.

## 7. 그림으로 뽑기

- **PNG 저장** : 배율(1x~4x) 선택 후 저장. 문서 삽입용은 2x 이상 권장
- **SVG 저장** : 파워포인트 / 일러스트레이터에서 크기 손실 없이 편집 가능
- **인쇄 / PDF** : A4 가로 PDF

편집용 클릭 영역과 선택 표시는 저장 파일에 포함되지 않습니다.

## 8. 설정 파일 직접 편집

`chart-config.js` 를 편집기로 열어 고치고 새로고침하면 됩니다(주석에 사용법 정리).
툴바의 **설정(JSON)** 버튼으로 화면에서 JSON을 직접 손보고 **적용**할 수도 있습니다.
주석이나 후행 콤마가 있는 JS 객체 형태도 그대로 읽습니다.

### 행 추가 예시

```js
{
  label: '통신 / 지상국',        // \n 으로 두 줄 가능
  height: 96,                   // 생략하면 기본 높이
  bars: [
    { start: '2026-Q2', end: '2027-Q2.5', label: '데이터링크 설계' },
    { start: '2027-Q2.5', end: '2028-Q4', color: 'gold', label: '지상국 통합 시험' }
  ],
  markers: [
    { at: '2027-Q2.5', type: 'filled', color: 'navy', label: '설계 검토', labelDy: -12 }
  ],
  deliverables: [
    { at: '2028-Q2', label: '지상국 시험 성적서' }
  ]
}
```

### 범례

차트의 범례 항목을 **클릭하면** 문구 · 색 · 모양 · 순서를 바꾸거나 지울 수 있고,
범례 박스의 빈 곳을 클릭하면 제목과 표시 여부를 바꿉니다. `+ 범례` 로 항목을 추가합니다.

```js
legend: {
  show: true,
  title: '범례',
  items: [
    { type: 'lineAlt', colors: ['sky', 'navy'], label: '수행 구간 (색 교대)' },
    { type: 'line', color: 'gold', label: '체계 통합 구간' },
    { type: 'marker', marker: 'diamond', color: 'green', label: '산출물' },
    { type: 'milestone', color: 'red', label: '핵심 마일스톤' },
    { type: 'triangle', color: 'steel', label: '계약 · 행정 이벤트' }
  ]
}
```

## 라벨이 겹칠 때

- 막대 문구: 인스펙터의 `문구 위치`(왼쪽/중앙/오른쪽)와 `▲▼` 버튼, 또는 `labelAt` `labelDx` `labelDy`
- 점 문구: `문구 위치`(위/아래)와 `▲▼`, 또는 `labelPos` `labelDy`
- 행이 좁으면 인스펙터에서 `높이` 를 키우고, 막대 위치는 `막대 위치 ▲▼` 로 조절합니다
- 한 행에 막대를 두 줄로 쌓으려면 막대에 `dy: -10`, `dy: 10` 을 줍니다
